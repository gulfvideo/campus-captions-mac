Event & welcome screen

Attendees who open the phone view see the welcome screen until you press Start event on the status page, and again after End event. The words sit on a dark panel over the image, so any photo keeps them readable. The logo sits in a slim row above the captions while they are live. The disclaimer appears once per device the first time someone opens the phone view, with a dismiss button — it reappears if you change the wording, but not just because you saved the field again.

Names & terms to get right —

Speakers, buildings, hymns — anything the recognizer would otherwise guess at. Type it, pick where it belongs, press Add. Deepgram is told this list directly; Whisper uses the first few dozen; the Apple backend ignores it.

Recognition tuning —

Defaults are good for a lecture or a service. Changes apply straight away — an open caption stream is closed and reopened to pick them up. Each setting only affects the backend it belongs to, so the ones for a backend you do not use can be ignored.
Deepgram
A committed word the model doubts this much is shown as [inaudible] rather than a confident wrong guess. 0 turns it off. Default 0.3.
Defaults: speaker changes on, filler words off.

int8 is fastest on a CPU; the float types need a GPU.
seconds
How often the in-progress line is redrawn. Default 0.9.
seconds of silence
How long a pause ends a line. Default 0.7.
Apple on-device speech
The language macOS recognises. Each one downloads a model the first time it is used. Default en-US.

Profanity filter —

Bleeps common strong language with no list to maintain. Words that are ordinary in a sermon — hell, damn, and ass as in the animal — are deliberately not filtered.

Slides + Captions —

—
Enable Network/API access in ProPresenter and enter its displayed port. Use 127.0.0.1 when ProPresenter runs on this same computer. To reach a different machine on the booth network, enter its private IP address and tick the local network box. Screen 1 is the first screen in the current Look. Enable audience output and that screen's Slide layer, then trigger a slide in Show view. Sharing starts during a live event. Attendees choose Aa → Slides + Captions on their phones. Static slide previews only; video, animations, and combined audience layers are not reproduced. Saving applies immediately and is remembered after restarting Campus Captions.

ProPresenter (direct) —

—
In ProPresenter: Settings → Network → Enable Network, and note the port. Stage message needs a stage layout with a Stage Message element on the screen that should show captions. Message needs a Message with the name above and one text token with the token name above — you design its look in ProPresenter; nothing else in the library is touched. Keep the Web Fill prop (wall URL) as the fallback. Line by line changes the surface once per finished sentence; word by word also sends the in-progress text, which is current but redraws the box under the reader. Captions are wrapped to at most two lines here, because ProPresenter reflows and shrinks whatever it is handed — set characters per line to what one line of your text box actually holds, and anything longer is shown as two lines and then paged. See SETUP.md 7a.

Wall output keys — OBS, vMix, Web Fill —

One key per output. While any key exists, a wall URL without a valid ?key= is refused, so revoking a key switches that output off without editing every scene and prop. With no keys, the plain wall URL works for everyone, as before. The tuner builds URLs with the key included. Phones are never affected.

How Campus Captions opens —

The status page, settings and the wall and phone views are web pages, but this is a program — so by default they open in their own window with no address bar and no tabs, and it gets its own entry in the taskbar or Dock.
—

Network — relay port —

—
If another program already has the configured port when Campus Captions starts, it starts on the next free one for that session and tells you. Saving a port here makes it permanent: the relay restarts on it straight away, the capture client follows, and this page moves with it. The wall and phone URLs and the printed QR code carry the port, so a ProPresenter prop, an OBS scene, or a poster made for the old port needs updating once.

Public tunnel (Cloudflare) —

—
One-time setup: at one.dash.cloudflare.com → Networks → Tunnels → Create a tunnel → Cloudflared → name it → add a Public Hostname pointing this event's subdomain at HTTP  localhost:8000 → copy the token shown in the install command. Paste the hostname and token above, then Enable — no restart needed. Needs the domain on Cloudflare's DNS and cloudflared installed (brew install cloudflared) — see SETUP.md 3c.
