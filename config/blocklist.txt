# "cashier". A multi-word phrase like "acme corp" is matched as that whole
# phrase, not each word separately. Edit this per event - no code changes,
# no restart. After editing, press "Reload keyterms" on the status page (it
# reloads this file too).
#
# This is separate from the profanity filter (a status-page toggle backed by
# a small built-in list of common strong language) - use this file for
# anything specific to this event: a name that must not be broadcast, an
# unannounced sponsor, a working title that leaked early.
#
# Unlike keyterms.txt, this applies after transcription, the same way on
# every backend - whisper, apple_speech, and mock all use it.
